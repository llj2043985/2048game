# 2048 小游戏

一个轻量、无需构建工具的网页版 2048 小游戏。打开 `index.html` 即可开始游戏。

## 功能

- 标准 4×4 棋盘与数字合成规则
- 支持方向键、WASD 和移动端滑动操作
- 实时得分与浏览器本地最高分记录
- 合成 2048 的通关提示，以及无路可走时的结束提示
- 响应式深色界面，适配桌面与手机浏览器

## 开始使用

1. 下载或克隆本项目。
2. 在浏览器中直接打开 `index.html`。
3. 通过方向键 / WASD / 手指滑动移动数字方块；两个相同数字碰撞时会合并。

也可以在项目根目录启动任意静态文件服务器后访问 `index.html`。

## 文件说明

- `index.html`：页面结构
- `style.css`：界面样式与动画
- `script.js`：游戏逻辑、输入处理与分数存储

## 游戏规则

每次有效移动后，棋盘会随机出现一个 `2` 或 `4`。将相同数字推到一起即可合成为更大的数字。合成 `2048` 即获胜；棋盘填满且所有相邻数字都不同，则游戏结束。
